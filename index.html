GitHub Pages Hosting

Jak mít web dostupný nonstop 24/7 zdarma

Krok 1

Vytvoř nový repozitář na GitHubu

Běž na github.com/new, pojmenuj ho (např. portfolio) a nastav jako Public.

Krok 2

Nahraj soubory webu do repozitáře

Máš dvě jednoduché možnosti:

  • Nejjednodušší způsob: V novém repozitáři na GitHubu klikni na "uploading an existing file" a jednoduše přetáhni soubory index.html, složku css a složku js.
  • Přes terminál (Git): Spusť v této složce:
    git init git add . git commit -m "Cyber Violet web" git branch -M main git remote add origin https://github.com/TVOJE_JMENO/portfolio.git git push -u origin main
Krok 3

Zapni GitHub Pages (1 kliknutí)

  1. V repozitáři klikni nahoře na Settings (Ozubené kolečko).
  2. V levém menu klikni na Pages.
  3. V sekci Build and deployment u položky Branch vyber main a složku / (root).
  4. Klikni na Save.
